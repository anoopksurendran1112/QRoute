# Requirements: QR-Based Indoor Navigation System

## v1 Requirements

### Authentication
- [ ] **AUTH-01**: Users can register and log in; admins are distinguished by role

### Location & Scanning
- [ ] **SCAN-01**: User can scan a QR code and have their current location identified

### Search & Discovery
- [ ] **SRCH-01**: User can search for a destination classroom by room number, department, faculty, building, or floor

### Pathfinding & Routing
- [ ] **PATH-01**: System computes the shortest path across buildings and floors using a weighted graph

### Mapping & Visualization
- [ ] **MAP-01**: App displays an interactive floor map with the route drawn on it

### Guidance
- [ ] **GUIDE-01**: App delivers turn-by-turn guidance, including floor transitions via stairs or lifts

### Admin - Campus Structure
- [ ] **ADMIN-01**: Admin can create, edit and delete buildings, floors, classrooms, departments and faculty

### Admin - Graph Authoring
- [ ] **ADMIN-02**: Admin can upload a floor plan and draw the walkable node/edge graph over it

### QR Code Management
- [ ] **QR-01**: Admin can generate, download and print the QR codes for graph nodes

### Monitoring & Analytics
- [ ] **MON-01**: System records navigation sessions and scan events for usage monitoring

### Demo Data
- [ ] **SEED-01**: A seeded synthetic campus exists so the system is demonstrable without manual setup
