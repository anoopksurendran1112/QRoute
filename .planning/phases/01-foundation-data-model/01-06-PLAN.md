  <name>Task 1: Typed API client, JWT decoding and the persisted auth provider</name>
  <files>apps/admin/src/api/client.ts, apps/admin/src/api/auth.ts, apps/admin/src/lib/jwt.ts, apps/admin/src/auth/AuthProvider.tsx</files>
  <action>
Create src/api/client.ts: a single `apiRequest<T>(path, options)` used by every future screen. Base URL is `import.meta.env.VITE_API_BASE_URL ?? "/v1"` so development goes through the Vite proxy and a built bundle can point elsewhere. It sets Content-Type application/json when a body is present, injects `Authorization: Bearer <token>` from the session getter, parses JSON only when the response has a body, and on a non-2xx response throws an `ApiError` carrying status, code (API error envelope code when present, otherwise a synthesised one) and message. Register a 401 handler hook that AuthProvider sets, so an expired token clears the session in one place instead of in every component. Never call fetch directly from a component or page.

Create src/api/auth.ts: `loginRequest(email, password)` posting to /auth/login and returning { token, user }, `meRequest()` hitting /auth/me, and re-exports of the shared request/response types from @qroute/shared so the panel and the API cannot drift.

Create src/lib/jwt.ts: `decodeToken(token)` splitting the JWT, base64url-decoding the payload and returning { sub, role, email, exp } or null when the shape is wrong, plus `isExpired(payload)`. State plainly in the module comment that this decode is for UI convenience only and never an authorisation decision — the API enforces the role on every write.

Create src/auth/AuthProvider.tsx: a React context exposing { token, user, status, signIn(email, password), signOut() }. Persist the token and the decoded user in localStorage under "qroute.token" and "qroute.user", rehydrate on mount, and drop the session when the decoded token is expired or malformed. signIn calls loginRequest, decodes the role from the token (do not trust a role field in the response body alone), stores both, and returns the user. signOut clears storage and the React Query cache. Export `useAuth()` which throws when used outside the provider.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → /v1 | Bearer token and credentials cross the network from an untrusted client |
| localStorage → app | Token storage readable by any script on the origin |
| Client role check → server | A UI-only gate that must never be the sole control |
