Export an ApiErrorCode union covering VALIDATION_ERROR, UNAUTHORIZED, FORBIDDEN, NOT_FOUND, CONFLICT, RATE_LIMITED and INTERNAL, plus an ApiErrorBody interface of shape { error: { code, message, details? } } that the API's error handler and the admin's client both use.

Create packages/shared/src/index.ts as the barrel that re-exports domain.ts with an explicit .ts extension (the repo's ESM import convention). The barrel exists so later plans add `export * from "./schemas/auth.ts"` and `export * from "./schemas/catalog.ts"` without every consumer changing its import path — plans 01-04 and 01-05 own those additions, and each lists index.ts in its files_modified.

Keep this file free of runtime dependencies on Prisma or Express: it is imported by a browser bundle as well as by Node.
